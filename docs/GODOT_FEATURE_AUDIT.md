# Godot feature audit: LastRoute Rust port

Generated by the `godot-feature-audit` workflow on 2026-11-01. This is a read-only static audit: nothing was built, run or played. Godot paths are relative to `LastRoute Godot/KyttusLabApp/`. Rust evidence lives in the workflow data, not in this file.

## Summary

Status uses `verified_status` where the audit verified a claim, and `rust_status` otherwise. Priority is the audit's judgement of how much the feature matters to the port.

| Status | Features |
|---|---|
| Features audited | 638 |
| Ported | 130 |
| Partial | 213 |
| Missing | 262 |
| Not applicable | 33 |

Verified claims: 60 claims carry `verified_status`. Of those, 14 are Night Watch (shell, shared framework and sound) and 46 are hunters and gimmicks. Every other status is an unverified static read of `rust_status`. Of the 351 ported or partial `rust_status` claims, the verifier changed 33 (25 ported became partial, 8 partial became missing).

Using `rust_status` alone the counts would be: ported 155, partial 196, missing 254, not applicable 33.

Entries marked `(verified)` below had their status confirmed by the verifier. Entries marked `skip` priority are kept for completeness but are not in the TODO list.

Night Watch is a separate executable (`src/bin/night_watch/main.rs`) that is only a placeholder in the Rust port. Its 125 entries are mostly missing. The Godot hub locks Night Watch for players, so it is not reachable in the Godot build yet.
