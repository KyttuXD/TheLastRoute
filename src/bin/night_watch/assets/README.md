# Night Watch assets

Art copied from the web reference set so the Rust Night Watch binary can embed it. The web set is read-only reference;
these copies are the ones `include_bytes!` reads (see `../data.rs` and `../sprites.rs`).

Source root: `C:\Users\Kyttu\Documents\Projects\LR Game Stuff\KyttusLab\games\night-watch\assets\`

Names match the source exactly. Nothing here is renamed.
