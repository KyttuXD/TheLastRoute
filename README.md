# KYTTU: The Last Route

A first-person survival horror game set in an endless facility. Every run starts fresh, and the facility keeps going down: district by district, with stairwells to deeper levels and hunters that grow more dangerous the more relays you recover.

> **Beta / work in progress.** The game is still being built. Expect bugs, rough edges, unfinished features and the occasional crash. Saves can break between versions. Please report what you find, with the steps to reproduce it.

## Getting the game

- **Windows:** `last_route.exe`
- **macOS:** `KYTTU The Last Route.app`, one app for both Apple Silicon and Intel Macs
- **Linux:** the `last-route-linux-x86_64` archive, with a binary, desktop entry and icon

Nightly builds are published on the [Releases](../../releases) page. They are rebuilt on every push to `main`, so they can be unstable.

The game needs a few system fonts (Courier New Bold and Impact on Windows and macOS). On Linux, if those aren't installed, Liberation Mono and Liberation Sans Bold are used instead.

## Reporting bugs

Open an issue with:
1. What you did, and what you expected to happen.
2. What happened instead (a screenshot or a short clip helps).
3. Your operating system and how you started the game.
4. The log file, if the game wrote one (see the wiki's troubleshooting page).
